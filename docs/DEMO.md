# Демонстрация участника №1

## Ваша зона ответственности

Показать, как бизнес превращает слабое описание в проверенную карточку, повышает её рейтинг и публикует. Вопросы/сохранение используют локальный адаптер до подключения сервера участником №2.

## Пример для защиты

Все сведения ниже синтетические; их вводит демонстратор.

1. Нажать пример «Заказы пекарни» и «Уточнить задачу».
2. Ответить, что пользователи — два администратора; результат — веб-прототип структурирования заказов; потребность — убрать повторный ввод. Остальные ответы пока пропустить.
3. Нажать «Собрать карточку»: предварительный рейтинг — 45.
4. Назвать задачу «Упростить обработку заказов пекарни».
5. Добавить доступные данные: «20 синтетических заказов в CSV» (+10) и способ передачи файла (+10).
6. Добавить показатель «Доля корректно обработанных заказов» (+10) и условие «Не менее 18 из 20, каждый менее чем за минуту» (+5).
7. Срок «7 дней» (+5), ограничение «Без реальных платежей» (+5).
8. Контакт `demo@example.com` (+5), «Два созвона в неделю» (+3), «Ответ на вопросы в течение рабочего дня» (+2). Получится 100.
9. Открыть предпросмотр. Показать, что сведения можно редактировать.
10. Отметить достоверность, подтвердить карточку, опубликовать.
11. Удалить условие приёмки. Предварительно будет 95, но в опубликованной версии ещё 100. Подтвердить правки и показать обновление.

Отдельная проверка слабой задачи: заполнить только название и минимальные сведения, подтвердить и опубликовать. Низкая оценка не блокирует действие.

## Что честно проговорить

Если `NEXT_PUBLIC_DATA_MODE=local`, это деморежим: AI не вызывается, данные находятся в браузере, общий каталог ещё не подключён. Не называйте локальную публикацию записью в Supabase. После подключения API этот же интерфейс вызывает серверные обработчики.

## Проверка перед передачей команде

- `npm ci`, `npm run typecheck`, `npm test`, `npm run build` проходят.
- Сохранённую задачу можно открыть после обновления страницы и через «Мои задачи».
- При возврате на предыдущий шаг введённый текст остаётся.
- Неподтверждённые правки не меняют опубликованную версию.
- Ни один UI-компонент не содержит секретных ключей.
- Участник №2 получил `docs/INTEGRATION.md`, участник №3 знает, что каталог читает только подтверждённую версию.
