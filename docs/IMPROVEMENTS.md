# Варианты следующих улучшений

Это предложения, не реализованные функции. Для хакатона сначала согласуйте объём с участниками №2 и №3.

| Вариант                                                                       | Польза на демонстрации                                  | Что нужно                                                                                 |
| ----------------------------------------------------------------------------- | ------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Подсказка «Улучшить формулировку» у каждого поля                              | Бизнес видит пользу AI на конкретном примере            | Серверный вызов модели участника №2; показать сравнение и применять только после согласия |
| Значки за этапы: «Описание готово», «Есть критерий успеха», «Бизнес на связи» | Геймификация становится заметнее                        | Вычислять достижения из подтверждённых полей, не раздавать баллы за клики                 |
| Экспорт карточки в PDF и копирование текста                                   | Готовый результат можно передать команде                | Печатная версия карточки и выбор подтверждённого снимка                                   |
| Русский / қазақша                                                             | Интерфейс становится удобнее для участников             | Словарь переводов и переключатель; пользовательские тексты не переводить без запроса      |
| История подтверждённых версий с сравнением                                    | Видно, как задача стала понятнее и почему вырос рейтинг | Хранение версий на стороне сервера; просмотр прежней и новой карточки                     |

Рекомендуемый порядок: настоящая AI-интеграция → экспорт карточки → достижения. Общий каталог, отклики студентов и выбор команды остаются отдельной частью команды, а не косметическими улучшениями конструктора.
